# Phase 4 — Annotation Canvas

## Goal
Full annotation and review capability inside the GUI, built in PyQt6 with agent
integration. User can annotate boxes and polygons, agent can push model predictions
to the canvas, and review mode lets users cycle through matches.

## Annotation engines (from Phase 1)

### Core engines → shared `tcip_annotation` package
The headless engines already exist as `packages/tcip-annotation/` (built in Phase 1).
The GUI imports them:

| Shared package | GUI usage |
|----------------|----------|
| `tcip_annotation.engine` | Canvas calls engine methods for CRUD, undo/redo |
| `tcip_annotation.review_engine` | Review panel calls matching + review state |
| `tcip_annotation.label_io` | Save/load YOLO format annotations |
| `tcip_annotation.matching` | IoU-based GT vs prediction matching |
| `tcip_annotation.state` | Shared data model for annotations |

### GUI (new PyQt6 implementation)
| Component | New (PyQt6) |
|-------------------------------|-------------|
| Annotation panel | `tcip_gui/panels/annotation_panel.py` |
| Review panel | `tcip_gui/panels/review_panel.py` |
| Canvas | `tcip_gui/widgets/canvas.py` |
| Dialogs | `tcip_gui/widgets/` |

The canvas is the biggest new piece: box/polygon drawing on QGraphicsView.

## Canvas architecture

```
┌─────────────────────────────────────────┐
│  QGraphicsView (viewport)               │
│  ├── QGraphicsScene                     │
│  │   ├── QGraphicsPixmapItem (image)    │
│  │   ├── BoxItem (QGraphicsRectItem)    │  ← annotations
│  │   ├── BoxItem ...                    │
│  │   ├── PolygonItem (QGraphicsPolygon) │
│  │   └── PolygonItem ...               │
│  └── Transform: pan, zoom, fit          │
└─────────────────────────────────────────┘
```

### Drawing tools
- **Box tool**: click-drag to create bounding box
- **Polygon tool**: click vertices, double-click to close
- **Select tool**: click to select, drag to move, handles to resize
- **Vertex edit**: drag polygon vertices (on select)

### Key interactions
- Mouse wheel: zoom (centered on cursor)
- Middle-click drag: pan
- Right-click: context menu (delete, change class, copy)
- Keyboard: Esc (deselect), Delete (remove), C (change class), Z (undo), Y (redo)
- Arrow keys: navigate images in dataset

## Agent ↔ Canvas integration

The agent pushes to the canvas via the `canvas_control` native Rust tool.
When the agent calls `canvas_control({action: "show_predictions", ...})`,
the Rust transport emits a `canvas.*` JSON-RPC message to the GUI.

### Agent → GUI (canvas messages, generated by `canvas_control` tool)

| Method | Params | Description |
|--------|--------|-------------|
| `canvas.load_image` | `{path, annotations?}` | Display an image, optionally with existing annotations |
| `canvas.show_predictions` | `{predictions_path}` | Overlay model predictions for review |
| `canvas.highlight` | `{annotation_ids}` | Flash specific annotations |
| `canvas.clear` | `{}` | Remove prediction overlay |

### GUI → Agent (new methods for Phase 4)

| Method | Params | Description |
|--------|--------|-------------|
| `canvas.annotation_saved` | `{image_path, count}` | User saved annotations for an image |
| `canvas.review_complete` | `{image_path, accepted, edited, rejected}` | Review stats for an image |
| `canvas.batch_complete` | `{summary}` | User finished a batch of images |

### Workflow: agent-assisted annotation

1. User: "Help me annotate these hazelnut images"
2. Agent calls `run_inference` (MCP tool) → model predictions
3. Agent calls `canvas_control({action: "show_predictions", ...})` → GUI overlays predictions
4. User reviews: accept good ones, edit wrong ones, add missed ones
5. User saves → `canvas.annotation_saved` → agent gets notification
6. Agent: "23 images annotated. Shall I train with the new data?"

### Workflow: review after inference

1. Agent calls `run_inference` on new images
2. Agent calls `compute_matches` with GT if available
3. Agent calls `canvas_control({action: "load_image", ...})` for each image
4. User enters review mode: cycles TP (green) / FP (red) / FN (blue)
5. User accepts/edits/rejects per annotation
6. `canvas.review_complete` → agent sees results, decides next action

## Test criteria (Phase 4 complete when)

1. Open app → load hazelnut image dataset → thumbnails appear in browser
2. Click image → canvas shows image → draw bounding boxes → save as YOLO
3. Draw polygons → vertex editing works → save as YOLO segment format
4. Undo/redo works for all annotation actions
5. Chat: "Run inference on these images" → agent calls `run_inference` + `canvas_control` → predictions overlay on canvas
6. Enter review mode → TP/FP/FN color-coded → cycle through with next/prev
7. Accept/edit/reject annotations → saves updated labels
8. Navigation: arrow keys to move between images, filter by status
9. Zoom/pan works smoothly on large images
10. All `tcip_annotation` engine tests pass
